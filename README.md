# Портфолио Александры Чканиковой

Статический сайт: редактура, копирайтинг, SEO, CRM, лендинги, интерфейсные тексты, PR и креативы.

Откройте `index.html` в браузере или разместите содержимое папки на статическом хостинге. Изображения находятся рядом с `index.html`; внешние зависимости и сборка не требуются.

Рекламные макеты — концепты для портфолио. Реалистичные изображения товаров в них созданы с помощью ИИ.
